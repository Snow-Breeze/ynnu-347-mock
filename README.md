# 云师大 347 应用心理 · 模拟题（每周一~五推送）

为 2027 云南师范大学应用心理专硕（347）备考编写的**模拟题系统**：每周一~五各一套，邮件推送网页链接。

## 出题依据

按历年真题结构 + 考点频次编拟：

| 依据 | 内容 |
|---|---|
| 题型结构 | 名词解释（5×5=25）＋简答（3×10=30）＋论述（1×20）＋综合分析（1×25），满分 100、建议限时 90 分钟 |
| 分值配比 | 统计 25 / 普心 25 / 发心 20 / 测量 15 / 教心 15（统计+测量占 40%，高于真题的 33%）|
| 押题规则 | ① 统计测量**每套必含**（多为研究情境应用题）② 近 3 年（2024–2026）考过的原题**避开** ③ 优先押"历史高频（≥3 次）但近 3 年未考"的角度 |

## 目录结构

```
mocks/mock-NNN.json    # 题目 + 标准答案（数据源）
mocks/mock-NNN.html    # 渲染后的网页（访问入口）
index.html             # 总目录
build_all.py           # 渲染脚本：json → html + index
push_mock.py           # 推送脚本：按日期找当天该发的套 → 发邮件
push_state.json        # 推送记录（幂等，防重复）
```

访问地址：`https://snow-breeze.github.io/ynnu-347-mock/`

## 维护

- **新增模拟题**：往 `mocks/` 放 `mock-NNN.json`（字段照旧），跑 `python3 build_all.py` 重新渲染，提交即可
- **改推送日期**：改 json 里的 `date` 字段（ISO 格式 `YYYY-MM-DD`）
- **手动测试**：Actions → 347模拟题推送 → Run workflow（`dry_run=1` 只演练）
- **本地预览**：`DRY_RUN=1 SMTP_USER=x SMTP_PASS=x python3 push_mock.py`

## 说明

- 推送时间：周一~周五，北京时间 6:30~7:40（GitHub 排队延迟补偿，实测区间）
- 收件人：只发备考者本人（`TO_EMAIL`）
- 本系统与《心理咨询师·每日一课》（`psych-daily-course`）、招生监控（`kaoyan-watch`）**互相独立**
